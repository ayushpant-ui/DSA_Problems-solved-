This repository contains my solutions to various Data Structures and Algorithms (DSA) problems. The purpose of this repository is to improve problem-solving skills, strengthen algorithmic thinking, and prepare for coding interviews and competitive programming.

* Greedy Algorithms
* Graph Algorithms
* Bit Manipulation
